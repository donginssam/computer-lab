# 개발 문서 안내

[프로젝트 README](../README.md)

프로젝트의 개발 환경, 구조, 화면 규칙, 검증과 배포 절차를 정리합니다. 시뮬레이터별 알고리즘과 구현 설명은 `theory/`에 보관합니다.

## 개발 문서

1. [개발 환경](development.md): 로컬 실행과 작업 명령
2. [아키텍처](architecture.md): 페이지와 기능의 책임 분리, 시뮬레이터 추가 방법
3. [화면과 용어 규칙](ui-guidelines.md): 디자인 토큰, 학생용 문구, 접근성
4. [검증](testing.md): 자동 테스트와 브라우저 확인 절차
5. [배포](deployment.md): GitHub Pages 설정과 배포 확인

## 시뮬레이터 이론과 구현

- [양팔저울 구현](theory/balance-scale.md): 문제 정의, 알고리즘, 최악 횟수, 실행 상태, URL과 기록 저장

## 문서 관리 원칙

- README는 프로젝트 소개와 개발 시작 방법을 안내합니다.
- 공통 개발 절차는 `docs/`, 시뮬레이터별 이론과 구현 계약은 `docs/theory/`에 기록합니다.
- 경로·스크립트·타입·화면 문구가 바뀌면 관련 문서도 함께 갱신합니다.
- 검증 결과에는 실행 날짜와 범위를 명시하고, 실제로 확인하지 않은 항목은 구분합니다.
