## 학생용 문구

한 개념에 같은 말을 써서 컨트롤과 설명을 연결합니다. 공통 라벨은 [copy.ts](../src/simulators/balance-scale/copy.ts), 알고리즘 이름은 [sequentialPair.ts](../src/simulators/balance-scale/engine/sequentialPair.ts)와 [divideHalf.ts](../src/simulators/balance-scale/engine/divideHalf.ts)의 `name`과 `shortName`을 기준으로 합니다. 모든 문장이 `copy.ts`에 모여 있는 것은 아닙니다.

| 개념                    | 사용하는 말                        | 피하는 말                          |
| ----------------------- | ---------------------------------- | ---------------------------------- |
| 찾는 동전               | 가짜 동전                          | 불량, 정답을 동전의 이름으로 사용  |
| 저울에 올리는 행동      | 저울질                             | 비교(알고리즘 이름은 예외)         |
| 양쪽 무게가 같음        | 양쪽이 같다 / 양쪽 무게가 같습니다 | 균형                               |
| 아직 제외되지 않은 동전 | 후보, 범례에서 뜻 설명             | 설명 없는 전문 용어                |
| 개수                    | 동전 수                            | 동전 개수                          |
| 이론 최대 횟수          | 가장 많이 걸려도                   | 가장 운이 나쁠 때, 최대 횟수       |
| 가짜 동전 배치          | 가장 늦게 찾는 곳                  | 가장 불리한 곳, 최악의 경우, 맨 끝 |

`가장 늦게 찾는 곳`은 위치, `가장 많이 걸려도`는 횟수입니다. 최악 위치는 항상 맨 끝이 아닙니다. 가장 늦게 찾는 곳을 화면 번호로 보면 N=7의 `차례로 비교하기`는 6번, N=100의 `절반씩 나누기`는 98번입니다. 비교 모드의 기준은 [양팔저울 이론 문서](theory/balance-scale.md)에 설명합니다.

정식 이름은 `차례로 비교하기`·`절반씩 나누기`, 좁은 표·범례는 `차례로`·`절반씩`을 씁니다. `bigOPlain`은 두 방법 모두 동전 수가 2배가 될 때 저울질이 얼마나 늘어나는지로 설명합니다. 현재 제목에는 `O(N)`·`O(log N)`이 보조 표기로 남아 있습니다. 바닥·천장 기호, 로그 수식, 느슨한 상한에 대한 설명은 개발 문서에 두고 학생 화면에는 횟수와 쉬운 문장을 씁니다.

개념 카드와 정리 질문 2개를 제공합니다. 개념 표와 질문의 N=128은 설명용이며 실제 실행 입력 범위는 2~100입니다.

### 문제 해결 전략 실험실

전략 이름과 각 실험의 행동을 같은 말로 연결합니다. 정식 이름이 길 때만 탭에서 짧은 이름을 씁니다.

| 개념                | 사용하는 말                                            | 피하는 말                |
| ------------------- | ------------------------------------------------------ | ------------------------ |
| 전략 1              | 시행착오 방법 / 탭에서는 시행착오                      | 무차별 대입, 브루트 포스 |
| 전략 2              | 욕심쟁이 방법 / 탭에서는 욕심쟁이                      | 탐욕 알고리즘, 그리디    |
| 전략 3              | 작은 문제로 나누어 해결하기 / 탭에서는 나누어 해결하기 | 설명 없는 분할 정복·재귀 |
| 자물쇠 한 번 돌리기 | 시도                                                   | 탐색, 검사               |
| 자물쇠 답           | 비밀번호                                               | 정답, 키                 |
| 동전 수 비교 기준   | 가장 적은 개수                                         | 최적해, 최소 해          |
| 더 고를 동전이 없음 | 막힙니다 / 쓸 수 있는 동전이 없습니다                  | 실패, 해 없음            |
| 카드 묶음 분리·결합 | 나누기 · 합치기                                        | 분할, 머지               |

`분할 정복`과 `합병 정렬`은 개념을 연결하는 보조 이름으로 사용할 수 있습니다. 학생이 누르는 설정과 실행 상태에는 `나누기`, `합치기`, `가장 많이 걸려도`처럼 관찰할 수 있는 행동과 결과를 먼저 씁니다. 질문 묶음은 fieldset 테두리나 문항 사이 구분선을 두지 않고 여백으로 나눕니다.

## 저울과 접근성

- `left`는 왼쪽이 가볍다는 뜻입니다. SVG 빔은 +8°로 회전해 왼쪽이 올라가고, `right`는 −8°, `balanced`는 0°입니다.
- 후보 상태는 색과 함께 ★·×, 텍스트 라벨로 구분합니다. 완료 전에는 가짜 위치를 공개하지 않습니다.
- 결과는 `role="status"`, `aria-live="polite"`로 전달합니다.
- 모드 탭은 선택 탭만 Tab 순서에 포함하고 방향키·Home/End를 지원합니다.
- 본문 건너가기 링크, 공통 `:focus-visible`, 입력 레이블을 유지합니다.
- `prefers-reduced-motion`에서는 저울 transition을 제거하며 그래프 애니메이션도 비활성화합니다.
- 360/768/1280px에서 확인합니다. 비교 화면은 좁은 폭에서 세로로 배치하고 실험 표는 내부 가로 스크롤을 허용합니다.

확인 시나리오는 [검증 문서](testing.md)에 있습니다.
